Verify the bytes you are reading

This site is deployed only by the deploy job of .github/workflows/verify.yml, which consumes the artifact the verify job produced and fetches every file back. The per-file SHA-256 manifest of the deployed tree is served at /_production/manifest.json: fetch any file here, compute sha256 of its body, and compare with files["evidence/…"]. The post-deploy attestation record for each deployment (commit, run ids, artifact id, per-file served digests, verdict) is published at https://raw.githubusercontent.com/mahmood726-cyber/meta-harness/production-records/<full commit sha>.json.
