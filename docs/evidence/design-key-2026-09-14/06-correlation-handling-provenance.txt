# Correlation-handling provenance and trusted-boolean plant

Removed shape:
retired trusted boolean flag for whether design correlation was accounted for

Replacement shape on every design-aware trial/study-effect object:
`correlation_handling: {method, evidence}`

Allowed methods:
published_model
published_adjusted_SE
reconstructed_with_ICC
paired_effect
none

Authority rule:
A method other than `none` with no evidence span normalizes to `none`. The action mapper then treats it exactly as missing correlation handling. This is the CAPE COD failure guard: a label is not authority.

Plant:
An object claiming `correlation_handling.method=published_adjusted_SE` with an empty evidence list on a reconstructed cluster design is refused exactly like `none`.

Plant test:
tests/test_design_key.py::test_correlation_method_without_evidence_is_treated_as_none_and_refused

PM/HKSJ boundary:
Production pools now pass a complete `study_effect` object for each study before strict pooling. Required fields are effect estimate, SE, estimand, analysis population, randomisation unit, study design, estimator method, correlation handling, and source provenance. `tests/test_synth.py::test_strict_pool_refuses_missing_study_effect_object` plants the missing-object refusal.
