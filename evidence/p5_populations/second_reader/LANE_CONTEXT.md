# LANE_CONTEXT — what this directory is

This directory is ONE isolated reading job from the meta-harness evidence lane `evid2` (P5 population evidence).
It contains: this file, `BRIEF.md` (the task), `row.json` (one trial included in a pooled review, the review's
topic requirements, and the facts to establish) and `doc*.txt` files (projections of held source documents of the
trial; each line of a JSON-derived file is `<pointer>: <value>`).

**Nothing outside this directory is context.** Do not read, search, or open any file outside it -- not your home
directory, not any AGENTS.md / CLAUDE.md / index / workbook elsewhere, not the network. If something you need is not
in this directory, the answer is that it is not stated here. Write only `out.json` in this directory.
