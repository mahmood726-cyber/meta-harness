## What to build

1. **One recovery pipeline.** Every registered harm outcome (`topics/<slug>.json` harms) runs through the SAME machinery as efficacy for EVERY trial in the canonical trial object (pooled + screened-in): extraction from cached abstract / CT.gov results / cached full text, `verify_basis`, `selection_rule` (source hierarchy), `estmeasure` class, compatibility key, k=2 refusal rules, claim-graph stamping. Grep how harms are built today (`harness/pipeline.py` — `harm_outcomes`, `kind == "harm"`, `_build_outcome`) and remove the divergence; if harms use a separate extractor path, the report must show the before/after row counts per page.
2. **Strands for harms** (reuse `docs/*_strands.json` shape / CG's strand objects): a harm outcome whose trials report different constructs (major bleeding vs ICH vs GI; diarrhoea vs GI intolerance vs any GI AE vs discontinuation; DKA vs genital infection vs amputation) renders as separate compatible strands with their own keys, never one collapsed label. Drug-specific signals (amputation/canagliflozin) get a `stratify_by: intervention_member` flag.
3. **Absence states for harms are the RR/metformin ontology**: `NOT_RETRIEVED` (source not in cache) / `RETRIEVED_OUTCOME_NOT_REPORTED` / `RETRIEVED_INCOMPATIBLE_STRUCTURE` (reported, not poolable: say why) / `RETRIEVED_REFUSED_WITH_REASON` / `KNOWN_REPORTED_NOT_YET_EXTRACTED` (the number is in the cached source — extraction debt, about us). `DECLARED ABSENT. no harms recorded` may render ONLY when every pooled trial's cached source is `RETRIEVED_OUTCOME_NOT_REPORTED`. A harms panel with k < (pooled trials whose source reports the harm) renders `HARMS_INCOMPLETE — n known reported outcomes unresolved (named)` and the gate refuses the k=1 row (CK's rule; implement here if CK's landing-2 patch is not on this base — check).
4. **Sparse data**: zero cells → continuity handling stated on the row, or refuse with `SPARSE_ZERO_CELLS` and show the counts; never a silent 0.5 without saying so (`advanced-stats.md`: add 0.5 ONLY if ≥1 cell is zero, and say so).
5. **Corpus sweep** `scripts/harms_recovery_sweep.py` → `docs/harms_recovery_sweep.json`: for all 32 topics × registered harms × pooled trials: source has the harm? extracted? state. Report `n harm outcomes rendered k<n_reporting_trials of N harm outcomes`, `n trials with KNOWN_REPORTED_NOT_YET_EXTRACTED of N pooled trials`, before/after per page.
6. Rebuild affected pages; `reproduce_review.py` each; quote every harms panel before/after for the 10 pages named.
