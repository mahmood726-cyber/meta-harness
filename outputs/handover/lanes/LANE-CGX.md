## Object classes (rendered with a visible class mark; machine-verified where the class allows)
- **FACT** — source-verifiable against a cited span: "LEADER reported HR 0.87 (0.78–0.97)". Verification: the span is located verbatim in the committed document; `document_sha256` + `retrieved_utc` on the edge. A FACT with no locatable span is `UNVERIFIED_FACT` and cannot be rendered as a fact.
- **TRANSFORMATION** — deterministic, recomputable: "log(HR) = −0.139", "k = 8", the pooled estimate, τ², PI, I², the count chain. Verification: recompute and compare (the existing `reproduction` limb generalised to every transformation object).
- **JUDGEMENT** — requires evidence and adjudication: "this endpoint is sufficiently compatible with the target"; "this trial is eligible"; a RoB domain rating; a GRADE domain decision; a comparator-parity relation. Carries `basis` (spans / rule id / model judgment with pin+cache per the reproducible-model contract) and `adjudication ∈ {RULE, MODEL_SPAN_VERIFIED, HUMAN(who, date), OWED}`.
- **INTERPRETATION** — where reasonable people differ: "the evidence suggests a clinically meaningful benefit"; rendered with at least one alternative reasonable formulation, never as a single sentence of fact.
Every rendered factual sentence on the page (manuscript, overview, cards, tables, dashboard, index) is a RENDERING of one object: the renderer calls `claimgraph.render(claim_id)`; a sentence with no object is a violation `SENTENCE_WITHOUT_OBJECT` caught by a scan of the rendered HTML against the object registry (the scan is the plant that makes typed prose impossible to reintroduce).

## Scope the graph MUST cover (the CLAIM-SCOPE FAILURE fix — today's misses were all here)
search completeness (chain + `entered_via` + rejection trail); registration precedence (protocol anchor commit vs build commit — `is_build_commit`); trial count and membership (families); endpoint definition per trial and canonical; result; significance; heterogeneity (Q, I², τ²); prediction interval; RoB coverage and each rating; publication bias assessed / not assessed and the basis; GRADE certainty AND each domain with its downgrade count (certainty must equal start − downgrades or render `provisional`); comparator overlap, parity, recency, rules-differ; reproducibility claims (byte-identical replay yes/no, from which SHA); every aggregate state sentence ("n declared absent", "coverage k of N", "n trials met eligibility") generated from the per-item states.
Plants (pre-fix on the base objects, each must fire): glp1 "Committed BEFORE the synthesis is run" vs "prospective precedence is not demonstrated"; glp1 "publication bias NOT ASSESSED" vs manuscript "assessed from the registry"; glp1 "moderate, 0 downgrades" arithmetic; ticagrelor "Coverage: 2 of 2 assessed" vs "1 of 2 rated"; corticosteroids-cap "seven declared absent" vs 5/1/1 states and the Torres refusal citing a rule the protocol lacks; colchicine-secondary "26 declared absent" vs none; COPS self-inconsistent refusal. `contradictions caught: n` prints its scope (`of N propositions in classes [...]`).

## Provenance DAG
claim → pooled effect (TRANSFORMATION) → trial estimates (FACT) → source span → `document_sha256` → `retrieved_utc` (+ for model judgements: prompt hash, model pin, cached response sha). `invalidate(changed_document_sha)` returns exactly the claims whose DAG passes through it; those render UNRENDERABLE until rebuilt (the existing `STALE_DEPENDENT` mechanism, generalised from `input_set_version` to document shas). Plant: mutate one cached span in a copy → the exact downstream claim set is invalidated and nothing else.

## Consumers
`page.py`, `limitations.py`, the manuscript renderer, `index.py`, `census.py`: replace typed sentences with `render(claim_id)` calls for every proposition in scope above; keep the visible class mark. The gate refuses `SENTENCE_WITHOUT_OBJECT`, `UNVERIFIED_FACT` rendered as fact, `JUDGEMENT` without basis, certainty arithmetic mismatch.
