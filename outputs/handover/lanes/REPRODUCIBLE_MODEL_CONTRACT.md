# Reproducible model-call contract — design decision from Mahmood, 2026-09-16 16:20

**Decision (Mahmood's words): "we can use some ai in harness as long as reproducible."** The old rule — *use a model only where the answer is not in the data* — is replaced by **a model may be used anywhere, provided its call is reproducible**: looser on placement, tighter on evidence. Recorded here, in `~/.claude/projects/C--meta-harness/memory/`, and in the Phase 2A/2B briefs so the screening rebuild is designed against it, not retrofitted.

## What "reproducible" means (all six, enforced by the gate — `verify_all` limbs, not convention)
1. **The model call is a SOURCE with the acquisition contract's five fields**: verbatim prompt; date; denominator and funnel (what was shown, what was asked, what came back); per-record decision with a rule id; the four states, and `RAN_ERROR` never folds into `RAN_ZERO`. Lives in the retrieval/decision ledger beside PubMed and CT.gov (`harness/acquisition.py` already has `MODEL_CALL` as a source kind — extend it to carry these fields).
2. **Pinned identity and decoding**, committed: model string, version/date, temperature, seed or top-p, max tokens, system prompt hash. An unpinned model is an unpinned dependency; the build refuses a judgment whose pin is missing (`MODEL_PIN_MISSING`).
3. **Response cached and committed** (`cache/<slug>/model_judgments/<task>.json`), so replay reads the committed response — the offline-reproduction limb never re-calls (the `outcome_judgments.json` pattern already does this on 1 of 32 pages; generalise it).
4. **Re-running from the protocol SHA regenerates the served page byte-for-byte** — unchanged definition of done; the model's cached response is an input like any other cache file.
5. **Deterministic post-check wherever one is possible**: every judgment cites the source span it relied on; the span must be located verbatim in the cached record (`SPAN_NOT_IN_SOURCE` refuses the judgment). A judgment with no citable basis is a proxy nobody re-checks and is refused, not rendered.
6. **Disagreement recorded, not resolved silently**: where a rule and a model disagree, both decisions are kept and rendered (`RULE_MODEL_DISAGREE(rule=…, model=…, adjudication=OWED|ADJUDICATED(by, date))`). Two AIs plus an adjudicator is the pattern; a silent override in either direction is a defect.

## What moves to a model call under this contract (judgement tasks a keyword list cannot do — today's regex failures)
| Task | Today | Under the contract | Post-check (item 5) |
|---|---|---|---|
| Population screen (truncated-title exclusion on metformin; diabetes-keyword veto on HFrEF trials; entry condition; severity; LVEF threshold; acute vs chronic; influenza status) | keyword presence/veto | model reads the record and returns `{entry_condition, severity_definition, lvef_threshold, acuity, span}` per axis | span verified; numeric fields (LVEF %) must appear in the span |
| Population vocabulary ("myocardial revascularization" = cardiac surgery) | lexicon list | model maps the record's population phrase to the protocol's population class, span cited | span verified; the mapping is cached per phrase |
| Randomised-contrast identification (MIRO-CKD, PYY1875, CRUSADERS: the drug in every arm; strategy bundles) | `drug_present AND placebo_present` | model enumerates arms and the isolated contrast → the arm object; rule then decides eligibility from the object | arm counts / drug names verified in the span; CT.gov `arm_group` cross-check where cached |
| Dose (HISTORI 1.0 mg vs 2.4 mg PICO) | bare drug name | model fills `dose` on the arm object from the span | the dose string must be in the span; comparison to the PICO dose is a rule |
| Endpoint identity across 3-/4-/5-component composites; co-primary selection; "same outcome as ours" | title substring | model enumerates components and timepoint per reported outcome; **the rule compares the enumerations** to the review's canonical set | each component must be named in the span; the canonical match is deterministic |
| Formulation / intervention class (IRONMAN derisomaltose vs FCM; steroidal vs non-steroidal MRA; dual SGLT1/2) | slug word | model classifies with span; rule compares to the protocol's admitted class list | span verified |
| Comparator equivalence (no corticosteroid / usual care vs placebo — REMAP-CAP) | bare "versus placebo" | model classifies the control arm into `COMPARATOR_CLASS`; the protocol states which classes are admitted | span verified |
| Design / masking / conduct flags (open-label END-AF; early termination; run-in) | registry field or absent | model reads design sentences → typed fields with spans; rule compares to the protocol | span verified; registry field kept as second source, disagreement recorded |

## What stays deterministic (the answer is in the data; a model here adds variance where there was none)
Identifier resolution (PMID/NCT/DOI); trial-family deduplication by identifiers (a model may *propose* a family from acronyms — the rule confirms by identifier or records `FAMILY_PROPOSED_UNCONFIRMED`); every arithmetic step (pooling, HKSJ, PI, RR/HR from counts, GRADE arithmetic inputs); participant-count reconciliation; round-trip checks (published effect vs 2×2); SHA/hash/anchor logic; membership, claim ids, input-set versions, the claim graph; rendering. The rule "a model never supplies a number" stands.

## Enforcement plan (Phase 2A screening rebuild — lane SF and successors)
- `harness/model_source.py`: one entry point `judge(task, record, prompt_template, pin)` that refuses without a pin, writes the ledger row, caches the response, verifies spans, and returns a typed object; nothing else in the harness may call a model.
- `verify_all` limb `model_source_discipline`: every rendered model-derived field traces to a committed cached response with pin + span verified; `RUN_ERROR ≠ RAN_ZERO`; disagreement objects rendered where present. Fails closed.
- Plants: the seven regex failures above become the acceptance set — each must flip to the correct decision under the model source **with a verified span**, and a synthetic record whose span does not contain the cited text must be refused.
