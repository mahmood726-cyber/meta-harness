# LANE HD — the heredoc/escape defect class made structural (Mahmood, 18 Sep): a round-trip byte assertion at the point of writing, a lint that REFUSES heredocs with backslashes in repo scripts, one sanctioned path, and the historical plant proven to fire pre-fix.

Report file: `LANE-HD-REPORT.md`. Base: main 2a5e0ee9 (record `git rev-parse HEAD`). No commit. No network.

## The class (three measured occurrences)
`\b` intended for a regex arrived as byte 0x08; `[/\\]` intended arrived as `[/\]` and silently swallowed the next alternative — and BOTH confirmation runs agreed with the wrong answer (zero hits read as confirmation of the standing conclusion); today, a lane brief written through a shell heredoc had `\f` in a Windows path turned into a form feed. The general form: a silent transformation between intent and artefact with nothing checking — the same shape as CRLF normalisation changing a held blob's digest. The standing rule ("write escapes through the Write tool, never a heredoc") has been measured to fail three times; the rule is not the fix.

## Build (all three layers; cheapest first)
1. **Round-trip assertion at the point of writing** — `harness/safe_write.py::write_bytes_verified(path, intended: bytes) -> sha256`: writes, re-reads, compares sha256 of the bytes on disk with sha256 of the intended bytes, raises `WriteRoundTripError` naming both digests and the first differing offset on mismatch; `write_text_verified(path, text, newline="")` for text (UTF-8, no newline translation unless asked); and `verify_file_bytes(path, expected_sha256)` for held artefacts (the CRLF case). Every script in `scripts/` that writes a file from a string literal containing a backslash must go through it (list the call sites you converted: `n of N`).
2. **A lint that refuses the construct** — `scripts/lint_heredoc_escapes.py` (+ a `tests/test_lint_heredoc_escapes.py` and a verify_all limb `heredoc-escape lint` that reads the lint's artefact): scan every `*.sh`, `*.ps1`, `*.py` (strings passed to `subprocess`/`os.system` with `<<`), `*.md` code fences that are shell (` ```sh`/` ```bash`) under the repo, find heredocs (`<<'EOF'`, `<<EOF`, `<<-`, PowerShell `@'…'@`/`@"…"@`) whose BODY contains a backslash → REFUSE (exit 1), each finding as `file:line: heredoc body contains backslash at line N: <the line>`; the error message names the sanctioned path (layer 3). Also refuse `python - <<'EOF'` bodies containing regex escapes. Run it on the whole tree and REPORT THE CURRENT COUNT (Mahmood expects more than zero); do not fix the historical scripts under `outputs/` silently — list them; fix the ones under `scripts/` and `.githooks/`.
3. **Remove the need** — the sanctioned path: content with escapes is written with `harness/safe_write.py` from a Python source file (never a shell string), or with the editor's Write tool; add `scripts/write_file_verified.py <path> <source-file>` as the CLI (reads the source file bytes, writes to path, round-trip-verifies, prints the sha256). The lint's refusal message says: "write it with scripts/write_file_verified.py or the Write tool; never through a heredoc".

## The plant (must fire PRE-fix; paste verbatim)
Reproduce the exact historical case through the production shell path: a `.sh` script with a heredoc whose body is `pattern = r"[/\\]"` and a Python consumer that compiles it; run it via `sh` on this machine; show the bytes that arrive (`[/\]` — hexdump) and show a regex search that returns zero matches on text that contains a forward slash → "confirmed clean" pre-fix. Then show layer 1 catching it (`WriteRoundTripError`, both digests) and layer 2 refusing the script. Regression test `tests/test_heredoc_roundtrip.py`: (a) the corruption is detected; (b) **a zero-match result cannot be reported as a clean pass unless the round-trip check has run** — encode this as an API: `safe_regex_scan(pattern_source_file, text)` returns `{matches, pattern_sha256_verified: bool}` and any consumer that reports "0 hits" must carry `pattern_sha256_verified: true`; a scan whose pattern was not round-trip-verified returns `UNVERIFIED_INSTRUMENT` rather than 0. A zero from a broken pattern and a zero from a correct one must be distinguishable — test both.

Report MEASURED: lint count on the tree (by directory), call sites converted, the plant's pre-fix bytes and zero-hit output, post-fix refusal, tests. Never a backslash escape through a heredoc — you of all lanes: write every file with the Write tool or your sanctioned helper. No commit.
