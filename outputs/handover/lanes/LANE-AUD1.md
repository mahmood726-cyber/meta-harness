## Defect 1 (the worst): a component-only result certified as verified 3-point MACE
A failure-injection audit at 3f8add72 fed the real glp1 outcome builder a synthetic abstract: "The primary outcome was 3-point MACE… No result for that composite is reported here. For cardiovascular death alone, HR 0.50 (0.30–0.80)". It returned pooled HR 0.50, endpoint EXACT_TARGET, components CV death/MI/stroke, verified, zero compatibility violations. Cause: the selector classifies the WHOLE abstract, then attaches that classification to a number extracted from ONE sentence — mentioning the composite anywhere launders a component-only result into the composite.
**Fix**: every effect object binds to its OWN endpoint-definition span AND its OWN result span; the endpoint identity of a number is decided from the sentence/table row that carries the number (and its definition span), never from the document-level classification. Finding the digits and finding the endpoint somewhere in the same document is not the same claim.
**Plant first (verbatim output pasted)**: run the production route (`build_topic`/the outcome builder on a synthetic cached abstract for a synthetic PMID in a scratch copy of the glp1 topic — no real cache mutated) with that abstract; show the pre-fix acceptance; then the post-fix refusal (`RESULT_INCOMPATIBLE` / endpoint-of-result ≠ target, with both spans named). ## Defect 2: the exact-3P rule admits 4P
