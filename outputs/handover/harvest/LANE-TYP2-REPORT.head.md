## Measurement contract

MEASURED: N is the fixed **49 baseline primary-pool rows plus harm rows carrying values**, across the ten assigned pages. Each row is keyed by page, outcome and source ID. Baseline review objects were captured before edits. FACT is the CGX hash/span/digit verdict, not an assurance of clinical compatibility. Fully typed means every protocol-binding axis is known; it does not imply matching the target. Refused means either FACT verification fails or type unification refuses. This denominator is retained even when a rebuilt page has no accepted pool.

The canonical additive cache is `cache/<slug>/verified_inputs.json`: value locks, document reference, SHA-256, exact span, Unicode character offset, source level, and axis evidence. `cache/<slug>/effect_types.json` is generated by TY through the pipeline. No type objects were hand-authored. Every accepted axis carries a held-document digest and verbatim located span; other axes remain UNKNOWN. Abstract hashes cover the UTF-8 bytes of the individual abstract field; full-text and structured registry-document hashes cover file bytes. Registry spans are literal original JSON outcome blocks, with their group IDs retained.

| Component | Static / human choice | Dynamic / measured |
|---|---|---|
| Scope | Ten assigned slugs | Baseline review rows read from disk |
| Estimates | No new or changed estimates | Numeric values locked against extracted rows |
| Evidence | Conservative selection of row-specific source spans | Hash, literal offset, committed source bytes and digits verified |
| Types | Literal interpretation of held wording; no protocol-to-row inheritance | TY builder, binding-axis unification, effect IDs |
| Coverage | Fixed baseline denominator | FACT, typed and refused counts recomputed |
